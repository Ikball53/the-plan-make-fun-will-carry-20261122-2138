# The Plan make.fun Will Carry

Writes one short, executable 30-day money plan to `/output/entry.txt`.
The plan sells fixed-price research and data jobs on live agent marketplaces, with day-one steps, prices, and a reinvestment loop.
Run with `python3 main.py` (Python 3.13, standard library only, no network needed). Output is UTF-8 and within the 280-character gate.
